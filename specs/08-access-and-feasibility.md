## 3. Hosting decision (answered 2026-10-02)
Preference: judges can use Prism with no complicated setup; fallback is running on this Mac only.

Plan — two helper modes, same code:
- **Hosted (default for judges):** Cloud Run service `prism-helper` (region `us-central1`), calling
  Vertex AI `global` with an attached service account (no key files exist anywhere). Judges install
  the extension and it works — no Google account, no terminal.
- **On this computer (developer mode):** the same helper on `127.0.0.1:8787` with your ADC sign-in.
  Settings → Prism service lets you switch.

Protecting your credits on a public URL (Origin checks alone are forgeable outside a browser):
- Per-install anonymous id (random, generated by the extension) + per-IP rate limits
  (e.g. 30 requests/min, 300/day per install), global daily cap (e.g. 3,000 requests/day), payload size
  limits, max 2 Cloud Run instances, request timeout 60 s.
- Google Cloud budget alert emails at $10 / $25 / $50.
- Free-trial accounts are not charged beyond the credit unless upgraded to a paid account (to be
  re-confirmed on the Billing page before deploy).
- Optional switch: require a short "judge access code" if abuse appears (off by default for ease).
- Payloads are never logged; only counts and latencies.

Distribution for judges: a downloadable zip (GitHub Release) + a 4-step "Load unpacked" guide with
screenshots. Note: the repo is **private** — judges need it public, a release link, or the Chrome Web
Store. Chrome Web Store (unlisted) is the easiest install for judges but needs a $5 developer account
in your name and review time of days; optional.

Other optional services: Microsoft Edge/Brave for extra compatibility checks; written permission for
OpenAI/Claude logos (not used — text labels instead).

## 5. Assumptions (proceeding with these unless told otherwise)
- A1. Chromium browsers (Chrome first) are the target; Firefox is a documented follow-up.
- A2. Prism's interface is English in this release; explanations/translations work in any language
  Gemini supports.
- A3. The default selection shortcut is Alt/Option + drag, configurable, with no-hotkey alternatives.
- A4. Chat is docked in the page (not Chrome's side panel) — see 02 §2.1.
- A5. Data stays in the browser + your Google Cloud project (local helper or your own Cloud Run
  service); no third-party server, no analytics.
- A6. Model routing: `gemini-3.8-flash` with LOW thinking for all features, `gemini-3.5-flash-lite` as
  fallback. Introductory price $0.75 / $3.75 per 1M input/output tokens (rises Jan 2027); a typical
  tidy ≈ 6–10k input tokens ≈ under $0.01; image request ≈ 1.1k image tokens.
- A7. Test data is synthetic; public-site checks never submit forms or sign in.

## 6. Feasibility limits (honest list)
1. **Browser-protected pages** (chrome://, new tab, Chrome Web Store, other extensions, built-in PDF
   viewer, view-source) cannot be tidied or scripted. Prism says so plainly.
2. **Held-key gesture needs site access.** A key press detected on the page does not grant Chrome's
   temporary `activeTab` access, so the hold-and-drag gesture only works where Prism already runs:
   after one toolbar click on that page, on sites set to "Always on", or everywhere if the person allows
   all sites. The popup button and command shortcut work without broad access.
3. **Screenshot of a region** needs `activeTab` or all-sites access per Chrome docs; whether a single-site
   grant suffices is unverified → tested in M4 with a clear fallback.
4. **Cross-origin iframes and closed shadow DOM** (e.g. embedded payment forms) can't be restyled
   inside or filled; Prism explains and uses screenshots for understanding.
5. **Canvas/WebGL apps** (maps, design tools) can't be restyled; Define/Translate still work.
6. **Synthetic events:** some sites check `isTrusted` and ignore script-generated input; Prism detects
   that the value didn't stick and asks the person to type it (with the suggestion to copy).
7. **Reordering:** only CSS-level reordering inside verified flex/grid containers; heavier layout
   restructuring is not attempted to protect site behaviour.
8. **OS-level shortcut conflicts** can't be verified by automation; a short manual checklist covers
   them.
9. **Non-technical install:** with the hosted helper, judges only install the extension. Without the
   Chrome Web Store, that still means Chrome's developer-mode "Load unpacked" (4 steps, guided).
10. **Chrome Web Store policy** prohibits interpreting remote commands; Prism's AI returns data mapped
    onto a fixed, packaged action set, which is designed to comply, but store review is untested.
11. **Free-trial accounts can't request quota increases**; heavy automated testing could hit 429s —
    handled with backoff + fallback model.
12. **Import formats** for ChatGPT/Claude exports are not officially documented in detail; parsers
    detect structure by shape and are tested on synthetic exports. A real export from the person would
    be a useful optional check.
